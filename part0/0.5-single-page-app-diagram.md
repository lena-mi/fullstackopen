
# 0.6: New note in SPA

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note right of browser: User writes a note and clicks Save

    browser->>server: POST /exampleapp/new_note_spa
    Note right of browser: Note content is sent in the request

    activate server
    Note left of server: Server saves the note
    server-->>browser: 201 Created
    deactivate server


    Note right of browser: Browser renders the updated notes
```
